# 项目理解指南（第 0 阶段）

## 这个项目只回答一个问题

临床数据中与哮喘相关的 VOC，不一定适合做成小型光子传感器。本项目把“值得测”和“能否测”接起来：先验证候选 VOC 能否跨队列复现，再检查它的红外吸收是否能避开水汽和二氧化碳干扰。

## 当前代码的数据流

```text
data/raw 中的公开文件
        ↓ discover_files()
识别 CSV / TSV / Excel / JSON 文件
        ↓ inspect_table()
读取表头、行列数、缺失率和候选字段
        ↓ build_audit()
汇总为机器可读的审计结果
        ↓
results/data_audit.json
```

现在不训练模型，因为如果标签、队列编号、样本配对或化合物字段并未公开，后面的模型即使运行成功也回答不了研究问题。

## 你需要先能解释的五件事

1. GC-MS 峰强度是仪器响应，不自动等于 VOC 的绝对浓度。
2. 环境空气也含 VOC；不校正可能把房间差异误认为疾病差异。
3. discovery cohort 用来提出候选，validation cohort 只用来检验已经锁定的候选。
4. 在验证集上反复改筛选规则，会造成数据泄漏。
5. 临床关联强不等于红外吸收强，也不等于适合少通道硬件。
